# Nexa Z-Wave

Homey app for Nexa Z-Wave devices.

## Supported devices

- **ZMD-107** motion sensor: motion, tamper and battery level
- **ZSD-109** smoke detector: smoke alarm, heat alarm, battery level and low-battery alarm

### ZSD-109 notes

- Pairing: add the device in Homey, then press the Test button three times within 1.5 seconds.
- Pressing the Test button turns the smoke and heat alarms on in Homey, so you can check that your flows fire.
- Dust, maintenance and end-of-life messages from the detector are ignored.
